# Credit Card Customer Segmentation

## Overview
This project applies customer segmentation techniques on credit card customer data using Machine Learning clustering algorithms.

The goal is to group customers based on their spending behavior, credit usage, purchases, and payment patterns to better understand different customer categories.

---

## Dataset
Dataset used:
- CC_GENERAL.csv

The dataset contains information about credit card customers such as:
- Balance
- Purchases
- Cash Advance
- Credit Limit
- Payments
- Installments Purchases
- Frequency features

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Project Steps
1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Feature Scaling
5. Exploratory Data Analysis (EDA)
6. Applying Clustering Algorithm
7. Evaluating Clusters
8. Visualizing Results

---

## Machine Learning Model
The clustering technique used in this project:
- K-Means Clustering

The model groups customers into different segments based on similar financial behaviors.

---

## Results
The project successfully identified multiple customer groups with different spending and payment behaviors.

These insights can help businesses:
- Improve marketing strategies
- Personalize customer offers
- Better understand customer behavior
