# Decision Trees and Random Forest Project

This project uses loan data to predict whether a borrower will fully repay the loan or not.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Models Used
- Decision Tree Classifier
- Random Forest Classifier

## Result
The Random Forest model performed better than the Decision Tree with higher prediction accuracy.

## Dataset
loan_data.csv
